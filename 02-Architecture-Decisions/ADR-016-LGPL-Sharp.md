# ADR-016: Использование sharp / libvips под LGPL-3.0

## Контекст

CodeInspectus (сканер безопасности, см. `AGENTS.md`) обнаружил, что бэкенд использует пакеты `@img/sharp-libvips-*` под лицензией **LGPL-3.0-or-later**. Это первый LGPL-компонент в проекте, использующем в остальном MIT / Apache-2.0 / BSD.

Требовалось принять решение: принять LGPL, заменить библиотеку или купить коммерческую лицензию.

## Что даёт sharp / libvips

- **Обработка изображений меню** (ADR-008): ресайз 1:1, конвертация в WebP, удаление метаданных, оптимизация q82.
- **Скорость:** в 4–7 раз быстрее чистых JS-реализаций (Jimp, ImageMagick-обёртки).
- **Надёжность:** libvips используется GitHub, Reddit, Wikimedia.
- **Совместимость:** динамическая линковка, MIT-обёртка `sharp` поверх LGPL-библиотеки.

## Решение

**Принимаем LGPL-3.0-or-later.** Код не меняем.

### Почему это допустимо

1. **LGPL ≠ GPL.** LGPL не требует открывать собственный код, если библиотека линкуется динамически.
2. **libvips не модифицирован.** Используется как готовая динамическая библиотека — значит, обязательства по публикации изменений не возникают.
3. **Коммерческое использование разрешено.** LGPL не запрещает продавать продукт (SaaS, приложение, курьерская платформа).
4. **Стандартная практика.** Все крупные компании (GitHub, Reddit, Amazon) используют libvips аналогичным способом.

### Обязательства, которые выполняем

1. **`THIRD_PARTY_LICENSES.md`** в корне репозитория — перечислены LGPL-компоненты, дана ссылка на исходники, заявлено об использовании.
2. **Ссылка в `README.md`** на этот файл.
3. **Проверка через CodeInspectus** — при добавлении новых зависимостей прогоняем `--scanner license`.

## Альтернативы (отклонены)

| Альтернатива | Причина отклонения |
|---|---|
| **`@napi-rs/image`** (MIT/Apache-2.0) | Меньше форматов, менее зрелый, хуже поддержка AVIF/WebP-нюансов |
| **ImageMagick CLI** | Зависимость от shell, медленнее, сложнее в Docker-образе |
| **Jimp** (чистый JS, MIT) | В 4–7 раз медленнее, пиковые нагрузки на CPU при загрузке фото меню |
| **Коммерческая лицензия libvips** | Публичных цен нет, ориентир $5,000–20,000/год. Несоразмерно проекту |

## Последствия

- ✅ Скорость обработки фото сохраняется.
- ✅ Код backend и frontend остаётся закрытым.
- ✅ Никаких лицензионных платежей.
- ⚠️ Один файл `THIRD_PARTY_LICENSES.md` нужно поддерживать актуальным.
- ⚠️ При появлении новых LGPL-зависимостей — обновлять файл.
